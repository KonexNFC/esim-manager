
Build a production-ready Next.js 14 (App Router) web + PWA for GlobeSIM, a tourist-first eSIM platform offering instant mobile data for UK inbound tourists, EU multi-country bundles, and Africa (Nigeria-anchored) regional plans.

Core Features
	•	Landing page with GlobeSIM branding and value proposition
	•	Destination selector (UK, EU, Africa)
	•	Plan cards (3, 7, 14, 30-day data-only plans)
	•	Stripe checkout (test mode wired, prod-ready)
	•	eSIM issuance orchestration (mock provider adapter first; clean interface to swap in real aggregator later)
	•	QR code + deep link install flow (iOS/Android instructions)
	•	Activation status tracker (step-by-step lifecycle: CREATED → ISSUED → INSTALLED → ACTIVE)
	•	User dashboard: data usage (mocked initially), expiry countdown, re-purchase CTA
	•	Admin console: profiles table, lifecycle state, retry issuance, manual refund trigger
	•	Webhooks: Stripe payment confirmation; carrier provisioning callbacks (mocked)
	•	Error handling, idempotency keys, retry logic, basic observability logging
	•	GDPR-compliant consent banner and privacy/terms placeholders

Tech Stack
	•	Frontend: Next.js App Router + Tailwind CSS
	•	Backend: Next.js API routes (Node.js)
	•	Database: PostgreSQL (Neon or Supabase compatible) via Prisma ORM
	•	Auth: Optional lightweight email magic link for tourists (can be feature-flagged off)
	•	Payments: Stripe
	•	QR generation: server-side QR code utility
	•	State management: lightweight client store
	•	Env management: .env with secrets

API Endpoints (implement stubs + contracts)
	•	POST /api/esim/issue
	•	POST /api/esim/activate
	•	POST /api/esim/retry
	•	POST /api/esim/refund
	•	GET  /api/esim/status/[profileId]
	•	GET  /api/plans?region=UK|EU|AFRICA
	•	POST /api/checkout/stripe
	•	POST /api/webhooks/stripe
	•	POST /api/webhooks/carrier

Data Models (Prisma)
	•	User (id, type: TOURIST|RESIDENT, email?)
	•	Device (id, imei, esimCapable, os)
	•	Plan (id, region, validityDays, dataAllowanceMb, price)
	•	eSIMProfile (id, userId, deviceId, carrierId, planId, state, qrUrl, expiresAt, lastErrorCode)
