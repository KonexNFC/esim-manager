Simplify the destination plans page for KONEX eSIM and optimise pricing psychology automatically.

IMPORTANT
Do not rebuild the whole site.
Do not change checkout, dashboard, admin, provider routing, or backend architecture unless required for plan display logic.
This task is focused on improving the destination plans page UX so customers see fewer, clearer, better-grouped plan options and convert faster.

PRIMARY GOAL
Reduce choice overload and improve conversions by:
1. showing a smaller curated default set of plans
2. grouping plans by trip type instead of showing every raw option at once
3. using pricing psychology to guide decisions
4. keeping full inventory available behind a “View all plans” interaction
5. adapting plan grouping logic by destination type

==================================================
1. CORE UX CHANGE
==================================================

Change the destination plans page from:
- large raw grid of every available plan
to:
- a curated, structured plan selector with grouped recommendations

By default, users should NOT see 20+ raw plans at once.

Instead they should first see:
- Short trips
- Standard trips
- Extended trips
- Heavy usage / Unlimited

Each group should display only 1–3 recommended plans by default.

Then provide:
- “View all plans”
- “Compare all options”
- or expandable advanced list

3. PLAN CURATION RULES
==================================================

For each trip bucket, automatically choose the most suitable plans from the existing inventory.

Selection logic should prefer:
- most relevant duration match
- best value by cost per GB
- strongest provider availability
- most commercially attractive option
- reasonable price progression

Do NOT show too many similar plans in the default curated view.

Default curated display:
- Short trips: show 1–2 plans
- Standard trips: show 1–2 plans
- Extended trips: show 1–2 plans
- Heavy usage / Unlimited: show 1–2 plans

Maximum visible in curated view at once:
- ideally 4–8 cards total
- not the full raw inventory

==================================================
4. PRICING PSYCHOLOGY RULES
==================================================

Optimise the order and labelling of displayed plans.

Use these principles:
- show a clear “Most Popular” plan
- show a clear “Best Value” plan
- show a “Heavy Usage” or “Unlimited” option
- make price jumps feel logical
- anchor value using higher-priced plans appropriately
- reduce low-value noise

Within the curated display:
- one plan should be visually highlighted as “Most Popular”
- one plan can be tagged “Best Value”
- one plan can be tagged “Unlimited” or “No limits”

Use cost-per-GB where helpful, but do not let it overpower clarity.

Display examples:
- Most Popular
- Best Value
- Best for short trips
- Best for 1–2 weeks
- Best for remote work
- Unlimited

5. LOW-VALUE PLAN FILTERING
==================================================

Reduce noise from low-value raw plans in the default view.

Do NOT surface tiny plans prominently in the curated default display unless they genuinely fit the destination profile.

Examples of plans that should usually be hidden from the default view:
- 100MB
- 500MB
- overly niche one-day plans
- too many near-duplicate 1GB/2GB/3GB variants

These can still exist in:
- “View all plans”
- advanced comparison mode

But do not let them dominate the first screen.
