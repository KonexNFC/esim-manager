6. PROVIDER ABSTRACTION LAYER
==================================================

Create a provider integration abstraction that allows GlobeSIM to switch providers later without rewriting business logic.

Implement a common provider interface such as:

ProviderAdapter:
- purchaseEsim(plan, customerContext)
- assignExistingEsim(plan, customerContext) if inventory model is used
- getEsimStatus(providerEsimId)
- getEsimUsage(providerEsimId)
- getEsimBalance(providerEsimId)
- getEsimQrCode(providerEsimId)
- getTopupOptions(providerEsimId or plan)
- purchaseTopup(providerEsimId, optionCode)
- getSupportedPlans()
- syncEsim(providerEsimId)

Create:
- BaseProviderAdapter
- MockProviderAdapter
- RealProviderAdapterPlaceholder

Use environment configuration so active provider can be selected cleanly:
- PROVIDER_NAME=mock
- PROVIDER_NAME=real_provider_name

==================================================
7. PROVIDER FULFILLMENT LOGIC
==================================================

After successful payment for an initial purchase:
- get order details
- create or link user
- call provider adapter to provision / assign eSIM
- save returned provider identifiers
- save QR code URL or activation code
- create dashboard entry
- mark order fulfilled if successful
- mark partially_fulfilled or failed if not successful
- trigger email / success notification

Build this as a service:
fulfillInitialPurchase(orderId)

For top-up payments:
- call provider purchaseTopup(...)
- save top-up record
- update eSIM balance if provider returns immediate updated data
- trigger confirmation notification

Build:
fulfillTopupPurchase(orderId)
