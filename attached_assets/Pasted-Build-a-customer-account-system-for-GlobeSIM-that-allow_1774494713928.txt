Build a customer account system for GlobeSIM that allows customers to log in after purchase, manage their eSIMs, view usage, and top up.

IMPORTANT
Do not rebuild the marketing site.
Keep the current landing page and funnel intact.
Add a proper post-purchase customer platform to the existing app.

PRIMARY GOAL
Turn GlobeSIM from a one-time purchase site into a customer account product with retention and repeat revenue built in.

PRODUCT OBJECTIVE
After buying an eSIM, customers should be able to:
1. access a customer dashboard
2. see their purchased eSIMs
3. view installation details and QR code again
4. see usage, status, and remaining validity
5. top up easily
6. view past orders
7. manage their account

==================================================
1. CORE USER FLOW
==================================================

Build this user journey:

A. Customer buys an eSIM
B. System creates or links a customer account using their email
C. Customer sees a success page with:
   - Install eSIM
   - Go to Dashboard
D. Customer also receives a magic login link by email (or mock this if email is not wired yet)
E. Customer can log in later and manage their eSIMs from a dashboard

Do NOT force account creation before checkout.
Account should be post-purchase and low-friction.

==================================================
2. AUTHENTICATION
==================================================

Implement a simple customer auth system.

Preferred auth methods:
- Magic link login (best option)
- Email + password fallback
- Optional placeholder structure for Google sign-in later

Initial version can support:
- Sign up
- Log in
- Log out
- Password reset or magic link placeholder

If full email auth is not wired yet, build clean frontend and backend structure ready for it.

Create these routes/pages:
- /login
- /signup
- /forgot-password
- /dashboard

UX requirements:
- Clean
- Minimal
- Mobile-first
- Premium fintech/telecom feel
- Low friction
