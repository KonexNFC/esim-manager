Build a production-level, conversion-optimised landing page for a global eSIM brand called GlobeSIM.

GOAL
Transform the current site from a basic demo-style page into a premium, high-converting landing page designed to drive plan selection and purchase. The site should feel modern, credible, mobile-first, and commercially ready.

PRIMARY OBJECTIVE
Increase conversion to plan browsing and eSIM purchase.

TARGET USERS
1. International travellers
2. Business travellers
3. Diaspora travellers
4. Digital nomads
5. Holidaymakers who want instant mobile data without roaming fees

CORE VALUE PROPOSITION
Global data in seconds. No roaming. No contracts. Instant eSIM activation.

BRAND POSITIONING
GlobeSIM is a clean, modern, premium travel connectivity brand. The experience should feel closer to a high-end fintech or premium telecom product than a generic travel site.

DESIGN DIRECTION
- Premium, sleek, minimal
- Mobile-first
- Confident commercial UI
- Spacious layout
- Strong hierarchy
- High trust
- Fast, lightweight, responsive
- App-quality feel

VISUAL STYLE
- Dark or light premium interface, but keep it clean and modern
- Use strong typography with excellent spacing
- Rounded cards, clean sections, subtle shadows or borders
- Refined, modern button styles
- Avoid clutter, avoid template look
- Prioritise premium UX over flashy effects

TECH STACK
Use the existing Replit web app stack if present.
If no clear stack is enforced, use:
- React
- Tailwind CSS
- Component-based structure
- Clean reusable sections
- Responsive design
- Accessible semantics
- Fast-loading layout
Do not introduce unnecessary dependencies.
