---
name: Travel image rules
description: User requirements for customer-facing photography and premium presentation.
---

Use commercially permitted photography hosted with the app for customer-facing destination and event imagery. Event photography may depict the destination rather than the event. Missing images use destination gradients with names, never flag-only fallbacks; countries without dedicated images may use clearly labelled regional inspiration.

**Why:** The user requested an image-led premium refresh while explicitly excluding prices, plan data, checkout, payment and routing changes.

**How to apply:** Preserve source licences and attribution, including ShareAlike for derivatives. Avoid press/agency imagery, brand or event logos/posters, and recognizable close-up people. Keep navy and sky blue; the new request permits a modern heading/body font pairing, superseding the earlier all-Space-Grotesk presentation requirement.
