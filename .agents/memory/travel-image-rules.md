---
name: Travel image rules
description: User requirements for customer-facing photography and premium presentation.
---

Use commercially permitted photography hosted with the app for customer-facing destination and event imagery. Event photography may depict the destination rather than the event. Individual country cards and heroes without a verified dedicated photo must use a named designed gradient/map fallback, never another country's landmark or a regional-inspiration caption. Regional photography is allowed only for region-level content.

**Why:** The user found cross-country regional photographs misleading and repetitive, and explicitly replaced the earlier permission for labelled regional fallback imagery. Prices, plan data, checkout, payment and routing changes remain excluded.

**How to apply:** Preserve source licences and attribution, including ShareAlike for derivatives. Avoid press/agency imagery, brand or event logos/posters, and recognizable close-up people. Keep navy and sky blue; the new request permits a modern heading/body font pairing, superseding the earlier all-Space-Grotesk presentation requirement.
