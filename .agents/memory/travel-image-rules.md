---
name: Travel image rules
description: User requirements for customer-facing photography and premium presentation.
---

Use commercially permitted photography hosted with the app for customer-facing destination and event imagery. Event photography may depict the destination rather than the event. Individual country cards and heroes use a verified dedicated photo first, otherwise that country's locally hosted SVG/WebP flag on a navy gradient, never emoji, another country's landmark, or generic globe-only artwork. Remove regional-inspiration captions from country surfaces. Regional photos are allowed only for region-level content.

**Why:** The user explicitly changed direction from designed-only fallbacks to each country's flag when a verified photo is unavailable. Prices, plan data, checkout, payment and routing changes remain excluded.

**How to apply:** Preserve source licences and attribution, including ShareAlike for derivatives. Avoid press/agency imagery, brand or event logos/posters, and recognizable close-up people. Keep navy and sky blue; the new request permits a modern heading/body font pairing, superseding the earlier all-Space-Grotesk presentation requirement.
